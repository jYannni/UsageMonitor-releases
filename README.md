# UsageMonitor releases

Signed, notarized builds of UsageMonitor for macOS (Apple silicon), and the
update feed the app checks.

- **Download:** the latest DMG is on the [Releases](https://github.com/jYannni/UsageMonitor-releases/releases) page.
- **Updates:** once installed, use *Check for Updates…* in the app's menu or Settings.
  The app reads `appcast.xml` from this repository's GitHub Pages site; every
  update is verified against an EdDSA key built into the app before it installs.
- **Support:** open an [issue](https://github.com/jYannni/UsageMonitor-releases/issues).

This repository holds release artifacts only; source is not published here.
